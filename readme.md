## DASAR TEORI

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan halaman web yang dibuat dengan HTML, seperti warna, jenis dan ukuran teks, posisi elemen, serta tata letak agar website terlihat lebih menarik dan rapi. CSS bekerja menggunakan aturan gaya yang terdiri dari selector untuk memilih elemen HTML dan declaration yang berisi properti serta nilainya. CSS dapat diterapkan dengan tiga cara yaitu inline, internal, dan external, di mana external CSS paling efisien karena dapat digunakan pada banyak halaman. Beberapa properti yang sering digunakan antara lain font-family, font-size, font-style, dan font-weight untuk mengatur tampilan teks agar lebih mudah dibaca dan menarik.

##### penjelasan
File HTML bertugas sebagai kerangka konten. Bagian <head> memuat metadata, Google Fonts (Ma Shan Zheng & Noto Serif SC), dan link ke file CSS eksternal. Di dalam <body>, elemen-elemen disusun berlapis dari belakang ke depan: dimulai dari dua div.bg-circle sebagai cincin pulsating di latar, lalu div.curtain kiri dan kanan sebagai hiasan tepi bernuansa kain sutra merah.
Setelah itu ada lima lantern, masing-masing terdiri dari empat bagian bersarang yaitu string (tali), cap (topi emas), body (badan berisi karakter 福), dan tassel (rumbai bawah yang bergoyang). Di samping lantern, ada sepuluh angpao dengan karakter berbeda-beda (福喜财禄) yang akan jatuh dari atas layar secara terus-menerus.
Bagian tengah halaman adalah .stage yang memuat konten utama: badge tahun, judul besar, karakter Mandarin, garis pembatas dekoratif, teks subtitle, dan blessings bar berisi empat karakter keberuntungan. Terakhir, sebuah blok <script> kecil membuat 40 partikel emas secara dinamis dengan posisi, ukuran, dan durasi animasi yang acak.

#### penjelasan
File CSS mengatur seluruh tampilan dan gerakan. Di bagian atas, :root mendefinisikan CSS variables untuk warna merah dan emas agar konsisten di seluruh file. Background halaman menggunakan radial gradient gelap kemerahan, ditambah noise texture SVG melalui pseudo-element ::before untuk memberi kedalaman visual yang lebih kaya.
Setiap komponen punya gaya tersendiri. Lantern menggunakan radial-gradient untuk simulasi cahaya dari dalam, rusuk dibuat dengan repeating-linear-gradient, dan efek ayunan dihasilkan oleh @keyframes swing yang merotasi elemen secara bergantian. Angpao jatuh menggunakan @keyframes fall yang menggabungkan translateY, rotate, dan perubahan opacity agar terlihat alami.
Untuk teks judul utama, animasi titlePulse mengubah intensitas text-shadow secara bergantian sehingga terlihat berpendar. Partikel emas kecil melayang ke atas menggunakan @keyframes sparkle dengan kombinasi translateY, scale, dan opacity. Sementara empat karakter blessing bergerak naik-turun dengan @keyframes charFloat, masing-masing diberi animation-delay berbeda agar gerakannya tidak sinkron dan terlihat lebih hidup.
